# 可复现验证

仓库只包含合成测试场景的生成代码，不包含私人输入、项目模型、聊天记录或特定电脑的验收日志。

## 自动检查

在仓库根目录运行：

```sh
python -X utf8 tests/run_checks.py --blender blender --out ./test-output
```

`--blender`可传可执行文件完整路径。输出目录必须为空；测试结果保存在该目录，不应提交到仓库。外部Python需要Pillow，场景由Blender在测试时创建，不下载权重。

覆盖内容：

- 非原点、不同尺度的三部件合成对象，场景包含未选中的地面与干扰对象。
- 圆端帽扫掠的闭合与组件，以及重复点、尖点和反向路径的拒绝。
- 保护对象变动、开放实体、程序材质未烘焙、渲染源失效、意外裁切、远程贴图等失败情形。
- 真实渲染、显式贴图导出、FBX/OBJ重新导入、文件哈希与压缩包CRC。
- 候选状态不会因为脚本通过而自动变成用户认可。

## 手动页面检查

打开测试输出中的`review/review.html`：

1. 真实拖动模型并复位；切换白模和材质，确认显示确实改变。
2. 原图渐变在0/25/50/75/100%查看；切换分界与同画布局部区域。
3. 自动渐变应改变画面，暂停后画面应稳定；切换多视角页。
4. 确认没有缺失资源、浏览器错误或使用静态海报冒充三维模型。

## 验证边界

当前工具在Blender 5.1及Python 3.12/3.13环境验证。其它版本应自行运行测试。数据检查不等于视觉还原验收；代理仍需观察参考图和整体结构，并根据反馈迭代。仓库不宣称已覆盖任意新图片、所有游戏引擎、骨骼动画、生产纸样或实物强度。
